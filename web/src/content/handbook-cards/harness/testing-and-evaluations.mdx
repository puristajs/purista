---
title: Testing & Evaluations
description: Test the real definition and standard loop with deterministic provider fixtures.
---

Use `FakeModelProvider` to script provider responses without credentials or
network access. The test still exercises schemas, agent selection, tool calls,
outcomes, and session cleanup.

```ts title="Test a portable agent deterministically"
import { defineAgent, defineHarness } from '@purista/harness'
import { FakeModelProvider } from '@purista/harness/testing'
import { expect } from 'vitest'
import { z } from 'zod'

const answer = defineAgent('answer', {
  input: z.object({ question: z.string().min(1) }),
  output: z.object({ answer: z.string() }),
  prompt: input => ({ role: 'user', content: input.question }),
  instructions: 'Answer the support question.',
})
const definition = defineHarness({ name: 'support' }).addAgent(answer)

const provider = new FakeModelProvider({ strict: true })
provider.enqueueObject({ object: { answer: 'Reset the PIN in Settings.' }, finishReason: 'stop' })

const harness = await definition.getInstance({ model: { provider, model: 'fake' } })
const session = await harness.getSession('test:pin-reset')
try {
  await expect(session.agents.answer.run({ question: 'How do I reset my PIN?' }))
    .resolves.toMatchObject({ status: 'completed', output: { answer: 'Reset the PIN in Settings.' } })
  provider.assertExhausted()
} finally {
  await session.release()
  await harness.close()
}
```

Test interrupted approvals, rejection, stale resume data, cancellation, and
tool failure separately. Run adapter contract suites from
`@purista/harness/testing` for custom ports. Keep live provider smoke tests
explicitly gated and outside normal CI.
