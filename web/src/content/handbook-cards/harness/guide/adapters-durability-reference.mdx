## Adapter choices

| Need | Harness boundary |
| --- | --- |
| Provider-neutral inference | Install a provider addon and register a truthful model alias |
| Persisted history and runs | `StateStore` adapter |
| Scoped memory | `MemoryAdapter` |
| File access or command execution | `Sandbox` with least privilege |
| Restart-safe workflow state | Durable runtime, workspace store, and checkpoints |
| External tool server | MCP through an appropriate sandbox/HTTP boundary |
| Policy approval/audit | Optional governance adapter |

Start local with in-memory adapters. For restart-safe work, use the local
durable execution bundle only when its local filesystem and SQLite lifecycle
matches your deployment. Replace individual ports for managed database,
workspace, sandbox, or remote-worker requirements; do not make a direct model
or storage SDK call from an agent merely to avoid an adapter decision.
