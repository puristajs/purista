---
title: Expose AI capabilities over HTTP
description: Project mounted targets through normal PURISTA commands and streams.
---

Mounting a Harness creates no HTTP route. Add a normal command for an aggregate
response or a normal stream for live updates, then expose that Framework
definition through Hono. Browser chat uses AI SDK UI Message Stream v1.

Continue with [Invoke and expose a Harness target](/handbook/framework/build-ai-powered-services/invoke-and-expose-a-harness-target/).
