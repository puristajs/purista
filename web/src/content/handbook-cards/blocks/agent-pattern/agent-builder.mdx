---
title: Define agents with Harness modules
description: Use the native Harness definition language and the PURISTA service mount boundary.
---

PURISTA does not provide a second agent builder. Define AI behavior with
`defineHarnessModule(...)`, compose modules with `.use(...)`, and mount the
completed definition once in the owning service.

Continue with [Build and mount the first agent](/handbook/framework/build-ai-powered-services/build-the-first-attached-agent/).
