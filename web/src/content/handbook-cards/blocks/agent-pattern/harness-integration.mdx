---
title: Harness integration
description: Compose native Harness modules and mount one definition in the owning PURISTA service.
---

Use native Harness modules to separate agents, workflows, and tools. Compose
them into one service Harness definition, then call `mountHarness(...)` once.
Consumers declare the target address and contract and always invoke through
EventBridge.

Continue with [Build and mount the first agent](/handbook/framework/build-ai-powered-services/build-and-mount-the-first-agent/).
