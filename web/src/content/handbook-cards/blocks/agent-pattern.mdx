---
title: Build AI-powered services
description: Mount one portable Harness definition in a PURISTA service and invoke selected targets through EventBridge.
---

PURISTA uses native `@purista/harness` modules for agents, workflows, tools,
Skills, and guardrails. Compose one Harness definition per service, publish the
selected targets with one `ServiceBuilder.mountHarness(...)` call, and bind
runtime adapters through `getInstance(..., { ai })`.

Read the current [Build AI-powered services guide](/handbook/framework/build-ai-powered-services/).
