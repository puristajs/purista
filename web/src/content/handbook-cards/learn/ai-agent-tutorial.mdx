---
title: Build an AI-powered PURISTA service
description: Create a native Harness module, mount it once, and call it through a typed Framework boundary.
---

Start with the project-local `add:agent` command. It creates a native agent
module, the service's composed Harness definition, a deterministic fake-model
test, and the service mount policy. Add a command, stream, or queue only for the
consumer behavior the application needs.

Follow [Build and mount the first agent](/handbook/framework/build-ai-powered-services/build-the-first-attached-agent/).
