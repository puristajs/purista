Run the focused test:

```bash title="Verify the attached classification agent"
npx vitest run examples/banking/src/ai/customer-support-classification.test.ts
```

The first test proves the generated definitions contain the service-owned agent
queue and command, while its manifest allows no model-callable commands or
agents. The second starts the Hono endpoint, submits an allowed `account-a`
request, and checks that the scripted model received the account and text. It
also checks that low confidence returns `no-action`.

The third submits Bob's request for `account-c`. The endpoint returns `403` and
the scripted model receives no request. That is the important negative proof:
the business scope guard runs before customer text reaches the model.

This suite does not prove browser integration, request ownership persistence,
live model quality, provider failure handling, or downstream routing. Add those
features and their real integration tests before expanding this chapter's
claims.
