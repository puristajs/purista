You can follow this chapter without completing the classification chapter.
Start in an empty parent directory and create its standalone application.

```bash title="Create and enter the Guardrails project" replay="parent"
npm create purista@latest guarded-classification -- --runtime node --event-bridge default --non-interactive --defaults
cd guarded-classification
```

Install the public packages used by this focused example.

```bash title="Install the published packages" replay="project"
npm install --save-exact @purista/core@4.0.0 @purista/harness@3.0.0 @purista/harness-guardrails@3.0.0 @purista/harness-openai@3.0.0 zod@4.4.3
npm install --save-dev --save-exact @purista/cli@4.0.0 typescript@7.0.2 vitest@4.1.10 tsx@4.23.12 @biomejs/biome@2.5.8
```

Use the PURISTA CLI to create the capability owner, its native Harness agent,
and the application command that will invoke the published agent address.

```bash title="Generate Support, the agent, and its caller" replay="project"
npm run add:service -- support --description "Own support conversations and support automation" --non-interactive
npm run add:agent -- classify-support-message --service support --service-version 1 --description "Classify one support message with content guardrails" --non-interactive
npm run add:command -- classify-support-message --service support --service-version 1 --description "Classify one support message with the guarded agent" --non-interactive
```

The agent generator creates the native module, the service-level Harness
composition, the mount policy, and the `.mountHarness(...)` registration. The
command generator creates and registers the command builder. We will replace
their placeholders in the following pages.

Move the input and output contracts into a shared file. Both the agent and the
guardrail actions need the same schemas, and this layout avoids an import
cycle.

```ts title="src/harness/support/agent/classifySupportMessage/schema.ts" write
import { z } from 'zod'

export const classifySupportMessageInputSchema = z.strictObject({
	messageId: z.string().trim().min(1).max(80),
	text: z.string().trim().min(1).max(2_000),
})

export const classifySupportMessageOutputSchema = z.strictObject({
	category: z.enum(['account_access', 'card', 'transfer', 'other']),
	urgency: z.enum(['normal', 'urgent']),
	reason: z.string().trim().min(1).max(240),
})
```
