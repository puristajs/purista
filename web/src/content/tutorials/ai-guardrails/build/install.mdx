Start in an empty parent directory. This chapter creates its own project named
`guarded-classification`.

```bash title="Create and enter the Guardrails project" replay="parent"
npm create purista@2.2.0 guarded-classification -- --runtime node --event-bridge default --non-interactive --defaults
cd guarded-classification
```

Install the exact versions used by the lesson. `@purista/harness-guardrails` is
optional in applications that do not declare content rails.

```bash title="Install Framework, Harness, Guardrails, and test dependencies" replay="project"
npm install --save-exact @purista/core@4.0.0 @purista/harness@3.0.0 @purista/harness-guardrails@3.0.0 @purista/harness-openai@3.0.0 zod@4.4.3
npm install --save-dev --save-exact @purista/cli@4.0.0 @biomejs/biome@2.5.8 @types/node@26.2.0 @types/sinon@22.0.0 sinon@22.1.0 tsx@4.23.12 typescript@7.0.2 vitest@4.1.10
```

Replace `package.json` with this complete file.

```json title="package.json" write
{
	"name": "@purista/tutorial-ai-guardrails",
	"version": "1.0.0",
	"private": true,
	"type": "module",
	"engines": {
		"node": ">=24.15.0"
	},
	"scripts": {
		"add:service": "purista add service",
		"add:command": "purista add command",
		"add:agent": "purista add agent",
		"build": "tsc --noEmit",
		"demo": "node --import tsx src/demo.ts",
		"lint": "biome check .",
		"start": "node --env-file-if-exists=.env --import tsx src/index.ts",
		"test": "vitest run"
	},
	"dependencies": {
		"@purista/core": "4.0.0",
		"@purista/harness": "3.0.0",
		"@purista/harness-guardrails": "3.0.0",
		"@purista/harness-openai": "3.0.0",
		"zod": "4.4.3"
	},
	"devDependencies": {
		"@biomejs/biome": "2.5.8",
		"@purista/cli": "4.0.0",
		"@types/node": "26.2.0",
		"@types/sinon": "22.0.0",
		"sinon": "22.1.0",

```
Generate the capability owner, native agent, and application command.

```bash title="Generate Support, the agent, and its command caller" replay="project"
npm run add:service -- support --description "Own support conversations and support automation" --non-interactive
npm run add:agent -- classify-support-message --service support --service-version 1 --description "Classify one support message with content guardrails" --non-interactive
npm run add:command -- classify-support-message --service support --service-version 1 --description "Classify one support message with the guarded agent" --non-interactive
```

The CLI creates the portable agent module and test, one service-level Harness
definition, one mount policy, the command files, and both service
registrations. Run that generated checkpoint before editing it.

```bash title="Verify the generated Guardrails checkpoint" replay="project"
npm run build
npm test
```
