Start in an empty parent directory. This chapter creates an independent
`guarded-classification` project.

```bash title="Create and enter the project" replay="parent"
npm create purista@3.0.0 guarded-classification -- --runtime node --event-bridge default --non-interactive --defaults
cd guarded-classification
```

Install the published Framework, Harness, guardrail, and optional provider
packages.

```bash title="Install guardrail dependencies" replay="project"
npm install @purista/core@^4.0.0 @purista/harness@^4.0.0 @purista/harness-guardrails@^4.0.0 @purista/harness-openai@^4.0.0 zod@^4.4.3
npm install --save-dev @purista/cli@^4.0.0 @biomejs/biome@^2.5.8 @types/node@^26.2.0 @types/sinon@^22.0.0 sinon@^22.1.0 tsx@^4.23.12 typescript@npm:@typescript/typescript6@^6.0.2 vitest@^4.1.10
```

Generate the Support service and its agent with explicit non-interactive values.

```bash title="Generate the guarded agent" replay="project"
npm run add:service -- support --description "Classify and route customer support requests" --non-interactive
npm run add:agent -- classify-support-message --service support --service-version 1 --description "Classify one support message with content guardrails" --non-interactive --model-alias classification
```

The generated Harness definition lives under
`src/service/support/v1/harness`, beside the service that owns its mount.
