---
title: Define chunks and a final result
description: Replace generated unknown schemas with small request, progress, and completed-review contracts.
order: 62
---

Generate or confirm the stream before changing its contracts:

```bash title="Generate analyzeTransaction"
npm run add:stream -- analyze-transaction --description "Stream a short, bounded transaction review" --service banking-operations --service-version 1
```

The generator creates `schema.ts` with `z.unknown()` input and chunk
schemas. Replace those placeholders before writing a handler. The caller needs
an account and transaction identifier; the UI needs a predictable progress
value; and the completed review needs a small final value.

```ts title="src/service/bankingOperations/v1/stream/analyzeTransaction/schema.ts"
import { z } from 'zod'

export const analyzeTransactionInputParameterSchema = z.object({})

export const analyzeTransactionInputPayloadSchema = z.object({
  accountId: z.enum(['account-a', 'account-c']),
  transactionId: z.string().min(1),
})

export const analyzeTransactionChunkPayloadSchema = z.object({
  stage: z.enum(['received', 'checking', 'complete']),
  message: z.string(),
})

export const analyzeTransactionFinalPayloadSchema = z.object({
  status: z.literal('complete'),
  checkedSteps: z.literal(3),
})
```

Keep chunks separate from the final value. A chunk tells a client what is
happening now. The final value lets it decide that the short review is over.
Neither schema should include account balances, whole statements, or a claim
that a transaction is suspicious.

Use the generated builder imports, then attach the four schemas:

```ts title="analyzeTransactionStreamBuilder.ts"
export const analyzeTransactionStreamBuilder = bankingOperationsV1ServiceBuilder
  .getStreamBuilder('analyzeTransaction', 'Stream a short, bounded transaction review')
  .addPayloadSchema(analyzeTransactionInputPayloadSchema)
  .addParameterSchema(analyzeTransactionInputParameterSchema)
  .addChunkSchema(analyzeTransactionChunkPayloadSchema)
  .addFinalSchema(analyzeTransactionFinalPayloadSchema)
```

`addChunkSchema` and `addFinalSchema` validate values written by the producer
by default. Input schemas document a public contract, but the handler still
needs a business guard before it reads data.

```bash title="Typecheck the new contracts"
npm run typecheck
```
