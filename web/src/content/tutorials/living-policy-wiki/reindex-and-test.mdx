The published proposal has `indexedRevision: null` until the current page
revision is explicitly indexed. The tests prove an approved stale proposal
cannot overwrite the page and an indexed revision must equal the current
published revision.

```bash
npx vitest run examples/banking/src/wiki/repository.test.ts examples/banking/src/wiki/service.test.ts
```
