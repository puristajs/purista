---
title: Review and publish
description: Separate Erin’s review from Dana’s exact-revision publication command.
order: 185
status: published
---

Erin may approve or reject the proposal. Dana may publish an approved one, but
the publish command receives both expected revision numbers. If either source
or page changed after review, it returns a conflict and writes nothing.

```ts title="examples/banking/src/wiki/repository.ts"
if (expectedSourceRevision !== this.sourceRevision || expectedTargetRevision !== this.page.revision) {
  throw new HandledError(StatusCode.Conflict, 'The source or wiki page changed; review the current revisions again')
}
```
