---
title: Generate the API checkpoint
description: Generate the two commands that define the transaction API before writing their schemas or handlers.
order: 21
---

From your `example-bank` project, create the two API operations. You may have
already generated `recordTransaction` in the project-start chapter; the CLI
will tell you if it exists, which is safer than replacing it by hand.

```bash title="Generate transaction commands"
npm run add:command -- record-transaction \
  --service banking --service-version 1 \
  --description "Record an already-posted synthetic transaction"

npm run add:command -- list-transactions \
  --service banking --service-version 1 \
  --description "List synthetic transactions for one account"
```

The generator adds each definition to `bankingV1Service.ts` and creates a
`types.ts`, `schema.ts`, builder, and builder test under
`src/service/banking/v1/command/<commandName>/`. Use the generated folders as
the API boundary. Do not put HTTP route parsing or database calls in React.

```bash title="Check the CLI output before editing it"
npm run build
npm test
```
