This chapter adds behavior to a running PURISTA application. Its starting point
has `src/config/http.ts`, `src/http.ts`, a Banking version 1 service, and the
`getBankInfo` command. It has no transaction storage yet.

If you built the first chapter, keep your `example-bank` directory. Do not
generate another Banking service or another `getBankInfo` command.

If you arrived here independently, recreate the starting checkpoint:

```bash title="Create an independent project for this chapter"
git clone https://github.com/puristajs/purista.git
cd purista
node examples/banking/tutorial/replay.mjs --to first-command --out ../example-bank-api
cd ../example-bank-api
```

The replay runs the PURISTA CLI and applies the first chapter's source edits;
it does not require installing the framework monorepo. Use a new destination.
Node 24.15 or newer, npm, and access to npm's registry are required.

## Confirm the starting point

Run `npm test`; expect four passing tests. Then start the application:

```bash title="Start the existing Banking service"
npm run dev
```

In a second terminal:

```bash title="Check the starting command"
curl -i http://127.0.0.1:3000/api/v1/bank
```

Expect `200` and `{"name":"Example Bank","currency":"EUR"}`. Stop the
development server with Ctrl+C before generating or replacing files.

All following terminal commands run in this generated application directory,
not in the framework repository. Keep the files you already built.
Next, [define the transaction contract](/tutorials/transaction-api/define-transactions/).
