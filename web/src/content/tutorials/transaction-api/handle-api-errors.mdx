---
title: Return safe API errors
description: Distinguish malformed data from an idempotency conflict without exposing unrelated records.
order: 25
---

Test three failure paths while the API is still small:

| Request | Expected result | Why |
| --- | --- | --- |
| `amountMinor: 12.5` | `400` | The schema rejects fractional minor units. |
| Missing `currency` | `400` | The public command contract is incomplete. |
| Reused source ID with a changed amount | `409` | The retry describes a different transaction. |

Use `HandledError(StatusCode.Conflict, ...)` for the changed duplicate. Keep
the message about the caller's submitted source ID; never include an unrelated
account, transaction, or a stack trace.

```bash title="Send malformed input"
curl -i -X POST http://127.0.0.1:3000/api/v1/transactions \
  -H 'content-type: application/json' \
  --data '{"accountId":"account-a","sourceTransactionId":"bad-amount","bookedAt":"2026-01-15T12:00:00.000Z","amountMinor":12.5,"currency":"EUR","direction":"debit"}'
```

The response should be `400`. The test in the next step proves that this input
does not reach the repository.
