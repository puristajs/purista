The `Transaction` commands already depend on a repository resource. This
chapter replaces the temporary in-memory adapter with SQLite while leaving the
service builder, command builders, schemas, and HTTP routes unchanged.

SQLite is an application resource. The composition root creates it, injects it
through `getInstance`, and closes it after the `Transaction` service stops.
Transaction records never use StateStore.
