Create the UI source directories from the project root. The example keeps its
server package manifest at the project root, so these commands never assume
that ui/ has a separate package.json.

```bash title="Create the React application directories"
mkdir -p ui/src/test
```

Install the exact browser dependencies used by this tutorial. ai provides
the standard UI Message Stream v1 transport, @ai-sdk/react provides
useChat, and React 19.2.8 is the version tested by the example.

```bash title="Install the pinned browser dependencies"
npm install ai@7.0.90 @ai-sdk/react@4.0.93 react@19.2.8 react-dom@19.2.8
```

Initialize the default shadcn theme in the ui directory. The --cwd ui
argument tells the pinned CLI where the Vite app lives while the command still
runs from the project root.

```bash title="Initialize the default shadcn theme"
npx shadcn@4.20.1 init --defaults --cwd ui
```

The chat uses AI Elements 1.9.0. Each command below fetches one pinned registry
entry and vendors its source into the application. The generated files are
application code owned by this project; do not replace these commands with
@latest or handwritten copies.

```bash title="Vendor the pinned AI Elements components"
npx shadcn@4.20.1 add --cwd ui https://elements.ai-sdk.dev/r/1.9.0/conversation.json
npx shadcn@4.20.1 add --cwd ui https://elements.ai-sdk.dev/r/1.9.0/message.json
npx shadcn@4.20.1 add --cwd ui https://elements.ai-sdk.dev/r/1.9.0/prompt-input.json
npx shadcn@4.20.1 add --cwd ui https://elements.ai-sdk.dev/r/1.9.0/tool.json
npx shadcn@4.20.1 add --cwd ui https://elements.ai-sdk.dev/r/1.9.0/confirmation.json
npx shadcn@4.20.1 add --cwd ui https://elements.ai-sdk.dev/r/1.9.0/sources.json
```

```ts title="ui/vite.config.ts" write
import { fileURLToPath, URL } from 'node:url'
import tailwindcss from '@tailwindcss/vite'
import react from '@vitejs/plugin-react'
import { defineConfig } from 'vite'

export default defineConfig({
	root: fileURLToPath(new URL('.', import.meta.url)),
	plugins: [react(), tailwindcss()],
	resolve: {
		alias: { '@': fileURLToPath(new URL('./src', import.meta.url)) },
	},
	build: {
		outDir: fileURLToPath(new URL('../public', import.meta.url)),
		emptyOutDir: true,
	},
})
```

Create the React entry point and default theme styles.

```tsx title="ui/src/main.tsx" write
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { App } from './App.js'
import './index.css'

const root = document.getElementById('root')
if (!root) throw new Error('Missing React root element')

createRoot(root).render(
	<StrictMode>
		<App />
	</StrictMode>,
)
```
