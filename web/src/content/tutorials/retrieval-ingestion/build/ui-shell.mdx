The browser remains a normal React application. It does not import PURISTA or
know about EventBridge addresses. Its only contract with the backend is HTTP
and AI SDK UI Message Stream v1.

Create the source and test directories from the project root.

```bash title="Create the React application directories" replay="project"
mkdir -p ui/src/test
```

Create the browser entry document.

```html title="ui/index.html" write
<!doctype html>
<html lang="en">
	<head>
		<meta charset="UTF-8" />
		<meta name="viewport" content="width=device-width, initial-scale=1.0" />
		<title>Example Bank knowledge chat</title>
	</head>
	<body>
		<div id="root"></div>
		<script type="module" src="/src/main.tsx"></script>
	</body>
</html>
```
Use a separate TypeScript configuration because browser code does not have the
same globals as the Node service.

```json title="ui/tsconfig.json" write
{
	"compilerOptions": {
		"target": "ES2022",
		"module": "ESNext",
		"moduleResolution": "Bundler",
		"jsx": "react-jsx",
		"strict": true,
		"skipLibCheck": true,
		"allowJs": false,
		"allowImportingTsExtensions": false,
		"paths": {
			"@/*": ["./src/*"]
		},
		"types": ["node", "vite/client", "vitest/globals", "@testing-library/jest-dom"]
	},
	"include": ["src/**/*.ts", "src/**/*.tsx", "vite.config.ts", "vitest.config.ts"]
}
```
Tell shadcn and AI Elements where the UI source, stylesheet, and aliases live.

```json title="ui/components.json" write
{
	"$schema": "https://ui.shadcn.com/schema.json",
	"style": "new-york",
	"rsc": false,
	"tsx": true,
	"tailwind": {
		"css": "src/index.css",
		"baseColor": "neutral",
		"cssVariables": true
	},
	"aliases": {
		"components": "@/components",
		"utils": "@/lib/utils",
		"ui": "@/components/ui",
		"lib": "@/lib",
		"hooks": "@/hooks"
	}
}
```
Vite builds the React application into the root `public` directory. The Hono
service will serve that output later.

```ts title="ui/vite.config.ts" write
import { fileURLToPath, URL } from 'node:url'
import tailwindcss from '@tailwindcss/vite'
import react from '@vitejs/plugin-react'
import { defineConfig } from 'vite'

export default defineConfig({
	root: fileURLToPath(new URL('.', import.meta.url)),
	plugins: [react(), tailwindcss()],
	resolve: {
		alias: { '@': fileURLToPath(new URL('./src', import.meta.url)) },
	},
	build: {
		outDir: fileURLToPath(new URL('../public', import.meta.url)),
		emptyOutDir: true,
	},
})
```
Create a separate Vitest configuration for the browser environment.

```ts title="ui/vitest.config.ts" write
import { fileURLToPath, URL } from 'node:url'
import react from '@vitejs/plugin-react'
import { defineConfig } from 'vitest/config'

export default defineConfig({
	plugins: [react()],
	resolve: {
		alias: { '@': fileURLToPath(new URL('./src', import.meta.url)) },
	},
	test: {
		environment: 'jsdom',
		include: ['ui/src/**/*.test.tsx'],
		setupFiles: [fileURLToPath(new URL('./src/test/setup.ts', import.meta.url))],
	},
})
```
Load the DOM matchers once for all component tests.

```ts title="ui/src/test/setup.ts" write
import '@testing-library/jest-dom/vitest'
```
Add the React entry point and the default theme. The colors stay deliberately
simple so the lesson remains focused on the Framework and streaming contract.

```tsx title="ui/src/main.tsx" write
import { StrictMode } from 'react'
import { createRoot } from 'react-dom/client'
import { App } from './App.js'
import './index.css'

const root = document.getElementById('root')
if (!root) throw new Error('Missing React root element')

createRoot(root).render(
	<StrictMode>
		<App />
	</StrictMode>,
)
```
