Start in a directory where you keep tutorial projects. Pinning the creator makes
the generated starting point reproducible.

```bash title="Create the tutorial project" replay="parent"
npm create purista@3.0.0 example-rag -- --runtime node --event-bridge default --non-interactive --defaults
cd example-rag
```

Install every dependency by its public npm package name.

```bash title="Install the published dependencies" replay="project"
npm install
```

Use the PURISTA CLI to generate the two services and their public boundaries.
The following lessons replace the generated placeholders with the complete
implementations and keep every Harness definition inside the Knowledge service.

```bash title="Generate the service owned boundaries" replay="project"
npm run add:service -- identity --description "Authenticate users and resolve sessions" --non-interactive
npm run add:service -- knowledge --description "Own knowledge ingestion and retrieval" --non-interactive
npm run add:command -- login --service identity --service-version 1 --description "Create an opaque session" --non-interactive
npm run add:command -- resolve-session --service identity --service-version 1 --description "Resolve an opaque session" --non-interactive
npm run add:command -- run-ingest-knowledge --service knowledge --service-version 1 --description "Run the protected ingestion workflow" --non-interactive
npm run add:command -- search-knowledge --service knowledge --service-version 1 --description "Search one authorized knowledge collection" --non-interactive
npm run add:command -- run-answer-knowledge-question --service knowledge --service-version 1 --description "Run the protected answer agent" --non-interactive
npm run add:workflow -- ingest-knowledge --service knowledge --service-version 1 --description "Chunk, embed, and store a knowledge source" --non-interactive
npm run add:workflow -- retrieve-knowledge --service knowledge --service-version 1 --description "Embed a query and find matching chunks" --non-interactive
npm run add:agent -- answer-knowledge-question --service knowledge --service-version 1 --description "Answer with model selected retrieval" --non-interactive --model-alias answering
npm run add:tool -- query-knowledge-repository --service knowledge --service-version 1 --description "Query the tenant scoped vector repository" --non-interactive
npm run add:tool -- search-knowledge --service knowledge --service-version 1 --description "Search knowledge for the answer agent" --non-interactive
npm run add:tool -- store-knowledge-chunks --service knowledge --service-version 1 --description "Store embedded knowledge chunks" --non-interactive
npm run add:stream -- stream-answer-knowledge-question --service knowledge --service-version 1 --description "Stream a grounded answer" --non-interactive
```

Check that the generated project and configuration compile before adding the RAG logic.

```bash title="Check the scaffold" replay="project"
npm run build:server
```
