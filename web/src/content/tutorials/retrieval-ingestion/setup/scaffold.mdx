Create a fresh PURISTA project and enter it.

```bash title="Create and enter the RAG project" replay="parent"
npm create purista@2.2.0 example-rag -- --runtime node --event-bridge default --non-interactive --defaults
cd example-rag
```

```bash title="Install the published dependencies" replay="project"
npm install
```

Generate the CLI-supported Framework and Harness boundaries before filling their
bodies. `Identity` owns sessions. `Knowledge` owns collection access, ingestion,
retrieval, and answers. The host-tool definition is a small portable module added
when the retrieval agent is built.

```bash title="Generate the RAG boundaries" replay="project"
npm run add:service -- identity --description "Authenticate users and resolve sessions" --non-interactive
npm run add:service -- knowledge --description "Own knowledge ingestion and retrieval" --non-interactive
npm run add:command -- login --service identity --service-version 1 --description "Create an opaque session" --non-interactive
npm run add:command -- resolve-session --service identity --service-version 1 --description "Resolve an opaque session" --non-interactive
npm run add:command -- ingest-knowledge --service knowledge --service-version 1 --description "Chunk, embed, and store a knowledge source" --non-interactive
npm run add:command -- search-knowledge --service knowledge --service-version 1 --description "Search one authorized knowledge collection" --non-interactive
npm run add:agent -- retrieve-evidence --service knowledge --service-version 1 --description "Choose and run knowledge retrieval" --non-interactive
npm run add:workflow -- answer-knowledge-question --service knowledge --service-version 1 --description "Retrieve evidence and stream a grounded answer" --non-interactive
npm run add:stream -- answer-knowledge-question --service knowledge --service-version 1 --description "Stream a grounded answer" --non-interactive
```

```bash title="Check the generated project"
npm run build
```
