Retrieval-augmented generation, usually shortened to RAG, gives a model relevant
application data before it writes an answer. A complete RAG feature has two
connected paths: indexing prepares reviewed sources, and answering retrieves
evidence for each question.

PURISTA owns service boundaries, authentication, authorization, HTTP exposure,
the database resource, and address-first calls. The native Harness owns model
contracts, embeddings, the retrieval agent, its host tool, and the streaming
answer workflow.

```text title="The complete RAG path"
protected ingestion command
  -> collection edit guard
  -> chunk source text
  -> Harness embedding model
  -> PostgreSQL and pgvector resource

protected chat stream
  -> mounted Harness workflow
  -> retrieval agent chooses search_knowledge
  -> authorized PURISTA search command
  -> same Harness embedding model
  -> tenant-scoped pgvector search
  -> grounded answer with citations
  -> AI SDK UI Message Stream v1
```

The Example Bank source document makes the result easy to try without adding a
banking domain model. The final React UI uses shadcn, AI Elements, and AI SDK
`useChat`, so no PURISTA-specific browser library is required.
