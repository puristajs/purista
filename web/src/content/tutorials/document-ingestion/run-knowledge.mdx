Start the complete example:

```bash title="Build and start Example Bank"
npm run build:ui -w @purista/banking-tutorials
npm run dev -w @purista/banking-tutorials
```

Open `http://127.0.0.1:3010/`, sign in as Alice, choose **Account A**, and
press **Ingest sample guide**. The React UI posts to
`/api/v1/knowledge/documents`; `createBankingApplication()` has already
registered `bankingKnowledge`, its local queue, and its generated Hono route.
The opaque local session cookie supplies Alice's server-verified identity.

The focused test still starts its own small composition and supplies a
synthetic identity inside its test middleware:

```bash title="Run the knowledge-service test"
npx vitest run examples/banking/src/knowledge/service.test.ts
```

There is no Docker dependency. The local queue processes work in the same
process, and the repository is a JavaScript `Map`. It does not prove durable
jobs, stored vectors after restart, or a real vector-search service.
