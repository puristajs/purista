---
title: Transform legacy input
description: Turn validated wire data into the generated command's domain payload.
order: 42
---

The command already exists. Add the raw legacy schema to `setTransformInput`.
PURISTA validates that raw shape, runs the transform, and validates the result
against the command payload schema.

```ts title="importLegacyTransaction command builder"
.setTransformInput(legacyBankTransactionSchema, emptyParameterSchema,
  async (_context, payload, parameter) => {
    const [whole, fraction] = payload.amount.split('.')
    const amountMinor = Number(whole) * 100 + Number(fraction)
    if (!Number.isSafeInteger(amountMinor) || amountMinor <= 0) {
      throw new HandledError(StatusCode.BadRequest, 'The legacy amount is outside the supported range')
    }
    return { payload: {
      accountId: payload.account_ref, sourceTransactionId: payload.source_id,
      bookedAt: payload.booked_at, amountMinor, currency: payload.currency,
      direction: payload.dc === 'D' ? 'debit' : 'credit',
    }, parameter }
  })
```

Use the generated test to cover `D` and `C`, malformed decimal input, and an
overflow. Do not put this conversion in Hono: HTTP, a workflow, and direct
tests will then apply exactly the same banking rules.

```bash title="Run the generated command test"
npm test -- --run src/service/banking/v1/command/importLegacyTransaction
```
