If you completed account access, keep that application directory. It already
has the Banking service, transaction commands, local login, and business
guards. Do not generate another copy of them.

For an independent start, run this from a directory that does not already
contain the named folders:

```bash title="Create the integration chapter's starting project"
git clone https://github.com/puristajs/purista.git
cd purista
node examples/banking/tutorial/replay.mjs --to account-overview --out ../example-bank-integrations
cd ../example-bank-integrations
npm test
```

The replay uses published packages and the PURISTA CLI. It does not require
installing the framework monorepo. You need Node 24.15 or newer, npm, and
registry access. If you already have the framework checkout, run the replay
there with a new output directory. Expect nineteen passing tests.

All following edits and terminal commands run in the generated application.
Stop its development server before changing connected files.

## Describe the incoming record

Create this fixture:

```json title="fixtures/legacy-transaction.json"
{
	"source_id": "legacy-001",
	"account_ref": "account-a",
	"booked_at": "2026-01-15T12:00:00.000Z",
	"amount": "125.40",
	"currency": "EUR",
	"dc": "D"
}
```

This is the **wire format**: the shape another system sends. Our **domain
format** is the shape the banking commands already understand.

| Legacy field | Domain field | Meaning |
| --- | --- | --- |
| `source_id` | `sourceTransactionId` | Preserve the record ID for duplicate detection |
| `account_ref` | `accountId` | This example shares the account-ID namespace |
| `booked_at` | `bookedAt` | Keep the UTC timestamp |
| `amount: "125.40"` | `amountMinor: 12540` | Represent EUR cents as an integer |
| `dc: "D"` | `direction: "debit"` | Translate the direction code |
| `currency: "EUR"` | `currency: "EUR"` | No currency conversion |

The record does not contain trusted tenant or principal identity. Hono still
resolves those from the session. A source transaction ID names a record; it
does not select a more privileged caller or upstream source.
