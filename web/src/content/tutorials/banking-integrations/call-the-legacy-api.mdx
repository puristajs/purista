---
title: Inject and inspect a local legacy-bank adapter
description: Add an application resource for a mocked external dependency without making the tutorial depend on a network service.
order: 45
---

Generate a distinct command for importing a booked item by external ID.

```bash title="Generate the adapter-backed import command"
npm run add:command -- import-legacy-bank-transaction \
  --service banking --service-version 1 \
  --description "Import one booked transaction through the legacy-bank adapter"
```

Define an interface and deterministic local implementation. The service depends
on `LegacyBankClient`, so production can later supply an HTTP client without
changing the command or its posting guard.

```ts title="src/legacy-bank.ts"
export type LegacyBankClient = { getBookedTransaction(sourceId: string): Promise<LegacyBankTransaction> }
export class LocalLegacyBankMock implements LegacyBankClient {
  async getBookedTransaction(sourceId: string) { /* return fixed fixture or 404 */ }
}
```

Register the resource when building the service and provide the mock in the
application composition:

```ts title="Service and application composition"
const builder = new ServiceBuilder(serviceInfo).defineResource<'legacyBankClient', LegacyBankClient>()
const legacyBankClient = new LocalLegacyBankMock()
await bankingService.getInstance({ resources: { bankingRepository, legacyBankClient } })
```

The reference app exposes a clearly labelled read-only fixture route at
`GET /tutorial/legacy-bank/transactions/legacy-bank-debit-a-1`. It lets readers
inspect the wire shape; the command uses the injected resource and still guards
the transaction write.
