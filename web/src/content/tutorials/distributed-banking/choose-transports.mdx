---
title: Choose each dependency for one job
description: Keep event transport, queue transport, and future domain persistence separate.
order: 212
status: published
---

The profile gives every dependency a narrow role.

| Dependency | Configured responsibility | It does not prove |
| --- | --- | --- |
| NATS JetStream | PURISTA event and command bridge | Business-state persistence or exactly-once delivery |
| Redis | PURISTA queue bridge with its own key prefix | A relational source of truth |
| PostgreSQL | A supplied database for a later persistence checkpoint | That this application writes domain state to it today |

`createDistributedBankingDependencies` configures `NatsBridge` with the
`example-bank` topic prefix and `durableSubscriptionMode: 'strict'`. It
configures `RedisQueueBridge` with the separate
`example-bank:queue:` namespace. The connection locations are ordinary
environment configuration:

```text
BANKING_NATS_URL=nats://127.0.0.1:4222
BANKING_REDIS_URL=redis://127.0.0.1:6379
```

The supplied Compose password is a local development fixture. Do not reuse it
as a deployed secret or put production credentials in browser code, images, or
source control.
