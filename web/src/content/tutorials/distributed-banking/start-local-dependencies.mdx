Docker Compose starts NATS with JetStream enabled, Redis with append-only
persistence enabled, and a local PostgreSQL database. Every service has a
health check, so Compose can report whether the process itself is ready.

```bash
docker compose -f examples/banking/docker-compose.distributed.yml up -d
docker compose -f examples/banking/docker-compose.distributed.yml ps
```

The file publishes NATS client and monitoring ports (`4222` and `8222`), Redis
(`6379`), and PostgreSQL (`5432`) to the local machine for this tutorial. Run
it only on a machine you control. A green container health check does not prove
that a PURISTA application can authenticate, publish, enqueue, or recover a
job.

When you are done, remove the local tutorial containers and their volumes:

```bash
docker compose -f examples/banking/docker-compose.distributed.yml down -v
```
