The Harness package already includes zero-dependency SQLite storage for Node
24.15 or later. No database package is needed for this local chapter.

```bash title="Install the published packages" replay="project"

npm install --save-dev --save-exact @purista/cli@4.0.0 typescript@7.0.2 vitest@4.1.10
```

Configure durable retention on the native Harness definition. Both limits
apply to persisted complete turns. `historyWindow` is a different setting: it
only limits what a model sees during one call.

```ts title="src/harness/support/supportHarness.ts"
import { defineHarness } from '@purista/harness'
import { answerSupportQuestionAgent } from './answerSupportQuestionAgent.js'

export const supportHarness = defineHarness({ name: 'support-conversations' })
	.requireModel('primary', { capabilities: ['object'] })
	.defaults({ historyRetention: { maxTurns: 8, maxBytes: 32_000 } })
	.use(answerSupportQuestionAgent)
	.define()
```

Create one storage instance in the composition root and pass that same instance
to the mounted Harness runtime. The file is application configuration, not part
of the portable agent definition.

```ts title="src/createSupportService.ts"
import type { EventBridge, Logger } from '@purista/core'
import { sqliteHarnessStorage } from '@purista/harness'
import { openai } from '@purista/harness-openai'
import { HarnessConversationHistory } from './resources/HarnessConversationHistory.js'
import { supportV1Service } from './service/support/v1/supportV1Service.js'

export function createSupportService(
	eventBridge: EventBridge,
	logger: Logger,
	environment: Readonly<Record<string, string | undefined>> = process.env,
) {
	const apiKey = environment.OPENAI_API_KEY?.trim()
	if (!apiKey) throw new Error('OPENAI_API_KEY is required to run the conversation-history example.')
	const storage = sqliteHarnessStorage({
		file: environment.HARNESS_STORAGE_FILE?.trim() || 'conversation-history.sqlite',
	})

	return supportV1Service.getInstance(eventBridge, {
		logger,
		resources: { supportConversationHistory: new HarnessConversationHistory(storage) },
		ai: {
			models: {
				primary: {
					provider: openai({ apiKey }),
					model: environment.OPENAI_MODEL?.trim() || 'gpt-5-mini',
				},
			},
			storage,
			telemetry: { contentCaptureMode: 'NO_CONTENT' },
		},
	})
}
```

Harness closes its configured storage during service shutdown. A production
deployment can replace SQLite with the Postgres storage adapter without changing
the agent or command contracts. Multi-instance services require a storage
adapter designed for shared coordination.
