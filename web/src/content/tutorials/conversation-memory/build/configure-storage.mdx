Start in an empty parent directory. Create a project, then use its local PURISTA
CLI to add the service and agent.

```bash title="Create the conversation project" replay="parent"
npm create purista@3.0.0 support-conversations -- --runtime node --event-bridge default --non-interactive --defaults
cd support-conversations
```

```bash title="Install and scaffold the Support capability" replay="project"
npm install
npm run add:service -- support --description "Own support conversations" --non-interactive
npm run add:agent -- answer-support-question --service support --service-version 1 --description "Answer one question using bounded conversation history" --non-interactive --model-alias answering
```

The agent is a direct, portable Harness definition under the service that owns
it. The prompt mapper turns structured application input into one model
message. Harness validates the structured answer against the output schema.

```ts title="src/service/support/v1/harness/agent/answerSupportQuestion/answerSupportQuestionAgent.ts" write
import { defineAgent } from '@purista/harness'
import { z } from 'zod'

export const answerSupportQuestionInputSchema = z.strictObject({
	conversationId: z.string().regex(/^[A-Za-z0-9_-]{1,80}$/),
	question: z.string().trim().min(1).max(2_000),
})

export const answerSupportQuestionOutputSchema = z.strictObject({
	answer: z.string().trim().min(1).max(2_000),
})

export const answerSupportQuestionAgent = defineAgent('answerSupportQuestion', {
	model: 'answering',
	input: answerSupportQuestionInputSchema,
	output: answerSupportQuestionOutputSchema,
	instructions: [
		'Answer one support question in plain language.',
		'Use earlier messages in this conversation when they are relevant.',
		'Do not claim that you performed an account action.',
	].join(' '),
	prompt: (input) => ({ role: 'user', content: `Conversation ${input.conversationId}: ${input.question}` }),
})
```
`answering` is the explicit purpose model alias. The definition contains no
provider name or secret. The service binds that exact `ai.models` key later.

npm run build
