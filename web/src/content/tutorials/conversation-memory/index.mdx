This chapter builds a small Support service whose agent can use earlier messages
from the same conversation. You can follow it on its own after the create-project
chapter.

You will keep three responsibilities separate:

- **Harness storage** owns sessions, transcripts, run receipts, durable
  checkpoints, and waits.
- **Harness memory** stores facts that an agent or tool writes on purpose. It is
  separate from the transcript.
- **PURISTA StateStore** holds application state such as login sessions. It does
  not hold agent transcripts.

The application derives one opaque session id from trusted tenant, principal,
and conversation values. The mounted agent and the authorized read and clear
commands use that same id.
