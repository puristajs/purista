Create a fresh project and enter it.

```bash title="Create and enter the evaluation project" replay="parent"
npm create purista@3.0.0 agent-evaluation -- --runtime node --event-bridge default --non-interactive --defaults
cd agent-evaluation
```

Replace the generated manifest with the published Framework and Harness packages. The default evaluation remains credential-free.

```bash title="Install the evaluation dependencies" replay="project"
npm install
```

Generate the service-owned boundaries. The later pages replace the generated placeholders with the complete files shown here.

```bash title="Generate the evaluated boundaries" replay="project"
npm run add:service -- support --description "Own support classification" --non-interactive
npm run add:agent -- classify-support-message --service support --service-version 1 --description "Classify one support message" --non-interactive --model-alias classification
npm run add:command -- run-classify-support-message --service support --service-version 1 --description "Run one support classification" --non-interactive
```

```bash title="Check the generated project" replay="project"
npm run build
```
