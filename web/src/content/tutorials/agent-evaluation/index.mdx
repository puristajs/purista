This chapter teaches repeatable agent evaluation for a portable classifier
mounted by a PURISTA `Support` service. You create a fresh project, generate
the service, agent, and command with the CLI, then evaluate that exact native
Harness definition over a small versioned dataset. Deterministic scorers measure
observable behavior, and a change gate fails when accuracy drops.

Evaluation is an offline engineering workflow. It does not belong in a public
request handler, and it does not replace command tests, business guard tests,
or production observability.

The default evaluation uses a strict scripted provider. It proves dataset,
runner, scorer, aggregate, and gate wiring without credentials. It does not
measure model quality. The optional live evaluation runs the same dataset
against a named provider model and may fail the gate.

You will learn how to:

- version datasets, candidates, tasks, and scorers independently;
- execute the real portable agent for every case;
- start with deterministic checks before adding model judges;
- aggregate results across semantic segments;
- keep observations and accounting under application ownership;
- turn thresholds into a CI failure;
- keep runtime authorization tests separate from offline quality evaluation.
