This chapter teaches repeatable evaluation as an engineering capability. You
build a portable classifier, mount it on a PURISTA Support service, and evaluate
that exact native Harness definition over a small versioned dataset.

The Example Bank messages make classification concrete without expanding the
business domain. Deterministic scorers measure observable structured behavior,
and a change gate fails when accuracy or execution health regresses.

Evaluation is an offline workflow. It does not belong in a public request
handler, and it does not replace command tests, business-guard tests, routed
integration tests, or production observability.

The default candidate is a strict scripted provider. It proves the complete
evaluation system without credentials but does not measure model quality. An
optional runner evaluates the same definition and dataset against a named live
provider model.
