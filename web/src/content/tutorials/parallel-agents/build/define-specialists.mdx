Create a clean PURISTA project from an empty parent directory.

```bash title="Create and enter the parallel-agent project" replay="parent"
npm create purista@latest parallel-agent-workflow -- --runtime node --event-bridge default --non-interactive --defaults
cd parallel-agent-workflow
```

Use the complete published dependency and script contract.

```json title="package.json" write
{
	"name": "@purista/tutorial-parallel-agents",
	"version": "1.0.0",
```

```bash title="Install the parallel-agent dependencies" replay="project"
npm install
```

Generate the Support capability, both agents, their workflow, and the command
that invokes it. Keeping the CLI steps visible gives every definition its
standard service-owned location.

```bash title="Generate specialists, workflow, and command" replay="project"
npm run add:service -- support --description "Own support cases and support automation" --non-interactive
npm run add:agent -- assess-support-risk --service support --service-version 1 --description "Assess risk in one support case" --non-interactive
npm run add:agent -- plan-support-response --service support --service-version 1 --description "Plan a response for one support case" --non-interactive
npm run add:workflow -- analyze-support-case --service support --service-version 1 --description "Run bounded specialist analysis" --non-interactive
npm run add:command -- analyze-support-case --service support --service-version 1 --description "Run bounded specialist analysis for one support case" --non-interactive
```

This focused example keeps the two short agent definitions and workflow in one
portable Harness file. Remove the generated agent and workflow placeholders
before writing that composition.

```bash title="Remove superseded generated Harness placeholders" replay="project"
rm -rf src/harness/support/agent src/harness/support/workflow
```

The specialists use different strict output schemas and different model
aliases. They produce recommendations; PURISTA commands continue to own
authorization and business effects.
