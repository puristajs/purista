Locate both tagged results and validate them before returning the workflow
output. This merge is deterministic: it does not add another model round that
could omit or rewrite evidence.

```ts title="src/harness/support/supportCaseAnalysisHarness.ts"
const risk = results.find((result) => result.kind === 'risk')
const response = results.find((result) => result.kind === 'response')
if (!risk || !response) throw new Error('Support analysis did not return both specialist results')

return {
	caseId: context.input.caseId,
	risk: riskAssessmentSchema.parse(risk.value),
	response: responsePlanSchema.parse(response.value),
}
```

Define a Support resource for the business decision. The workflow target guard
from the previous step protects direct workflow callers. The command is a
second public EventBridge address, so it applies the same case-level policy
before invoking the workflow.

```ts title="src/service/support/v1/command/analyzeSupportCase/analyzeSupportCaseCommandBuilder.ts"
export const analyzeSupportCaseCommandBuilder = supportV1ServiceBuilder
	.getCommandBuilder('analyzeSupportCase', 'Run bounded specialist analysis for one support case')
	.addPayloadSchema(supportCaseInputSchema)
	.addOutputSchema(supportCaseAnalysisOutputSchema)
	.canInvokeWorkflow(
		'Support',
		'1',
		'analyze_support_case',
		supportCaseAnalysisHarness.contracts.workflows.analyze_support_case,
	)
	.setBeforeGuardHooks({
		caseAccess: async function (context, payload) {
			await requireSupportCaseAnalysis(context.resources.supportCasePolicy, {
				tenantId: context.message.tenantId,
				principalId: context.message.principalId,
				caseId: payload.caseId,
			})
		},
	})
```

Invoke the workflow by its address-first typed client. The explicit session id
keeps the case transcript and run history isolated by trusted tenant and
principal inside the mounted runtime.

```ts title="src/service/support/v1/command/analyzeSupportCase/analyzeSupportCaseCommandBuilder.ts"
.setCommandFunction(async function (context, payload) {
	const outcome = await context.workflow.Support['1'].analyze_support_case.run(payload, {
		sessionId: supportCaseSessionId(context.message, payload.caseId),
	})
	if (outcome.status !== 'completed') throw new Error('Support case analysis did not complete')
	return outcome.output
})
```

The session ID includes trusted tenant and principal identity as well as the
case ID. This prevents two tenants that choose the same case ID from sharing
Harness history. The focused command has no HTTP metadata; a later Hono
projection remains protected by default.
