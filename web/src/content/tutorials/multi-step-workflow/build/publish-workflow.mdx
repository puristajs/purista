The service owns the business decision about who may resolve a case.

```ts title="src/service/support/v1/SupportResources.ts" write
export interface SupportCasePolicy {
	canResolve(input: Readonly<{ tenantId: string; principalId: string; caseId: string }>): Promise<boolean>
}
```

Declare that resource on the Support service builder.

```ts title="src/service/support/v1/supportV1ServiceBuilder.ts" write
import { ServiceBuilder } from '@purista/core'
import type { SupportCasePolicy } from './SupportResources.js'

export const supportV1ServiceBuilder = new ServiceBuilder({
	serviceName: 'Support',
	serviceVersion: '1',
	serviceDescription: 'Owns support cases and resolution workflows',
}).defineResource<'supportCasePolicy', SupportCasePolicy>()
```

Use one authorization helper for both public boundaries. Missing trusted identity is unauthenticated; a rejected policy decision is forbidden.

```ts title="src/service/support/v1/requireSupportCaseResolution.ts" write
import { HandledError, StatusCode } from '@purista/core'
import type { SupportCasePolicy } from './SupportResources.js'

export async function requireSupportCaseResolution(
	policy: SupportCasePolicy,
	input: Readonly<{ tenantId?: string; principalId?: string; caseId: string }>,
) {
	if (!input.tenantId || !input.principalId) {
		throw new HandledError(StatusCode.Unauthorized, 'A valid session is required')
	}
	if (
		!(await policy.canResolve({
			tenantId: input.tenantId,
			principalId: input.principalId,
			caseId: input.caseId,
		}))
	) {
		throw new HandledError(StatusCode.Forbidden, 'Support case resolution is not allowed')
	}
}
```

Only the workflow is a mounted Harness root. Its agents remain private children. The target policy runs before the mounted workflow reaches either model.

```ts title="src/service/support/v1/harness/supportHarness.ts" write
import type { HarnessBusinessGuardContext } from '@purista/core'
import { defineHarness } from '@purista/harness'
import type { z } from 'zod'
import { requireSupportCaseResolution } from '../requireSupportCaseResolution.js'
import type { SupportCasePolicy } from '../SupportResources.js'
import { resolveSupportCaseWorkflow } from './workflow/resolveSupportCase/resolveSupportCaseWorkflow.js'

export const supportHarness = defineHarness({ name: 'supportResolution', revision: 'v1' }).addWorkflow(
	resolveSupportCaseWorkflow,
)

export const supportHarnessPolicy = {
	targets: {
		workflows: {
			resolveSupportCase: {
				beforeGuards: {
					caseAccess: async (
						context: HarnessBusinessGuardContext<{ supportCasePolicy: SupportCasePolicy }>,
						input: z.output<typeof resolveSupportCaseWorkflow.contract.input>,
					) =>
						requireSupportCaseResolution(context.resources.supportCasePolicy, {
							...context.identity,
							caseId: input.caseId,
						}),
				},
			},
		},
	},
} as const
```
