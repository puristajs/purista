Generate a separate support-guide agent. Keep classification and free-form
guidance separate so each agent has a small, understandable responsibility.

```bash title="Generate the support guide agent"
npm run add:agent -- guide-account-support \
  --service banking-support --service-version 1 \
  --description "Guide an authorized read-only account support request"
```

Create `src/ai/skills/banking-support-playbook/SKILL.md` with reviewed,
read-only instructions. Bind it by name in the application composition and then
configure the generated builder:

```ts title="support guide builder"
.useSkills(['banking-support-playbook'])
.useBuiltInTools(['read'])
.setHarnessAgent({
  model: 'primary', input: supportPlaybookInputSchema, output: supportPlaybookOutputSchema,
  instructions: 'Provide read-only bank support. Read the banking-support-playbook Skill before answering. Follow it exactly.',
})
```

The model sees a Skill catalog entry and uses the restricted `read` tool to load
the reviewed file. Reading instructions grants neither an account permission nor
a new banking command.
