---
title: Keep the tool read-only and bounded
description: Keep a generated agent's capabilities smaller than the service around it.
order: 152
status: published
---

The agent has exactly one allowed command: `banking.1.listTransactions`. Do not
give this classifier a posting command, a queue action, a generic HTTP client,
or agent delegation. The generated agent is useful because it classifies a
request, not because it can perform every banking action.

Add the request's business guard before the model call:

```ts title="A guard is a business assignment check"
.setBeforeGuardHooks({
  customerSupportScope: async (context, payload) => {
    if (!context.resources.bankingRepository.canRead(context.message.principalId, payload.accountId)) {
      throw new HandledError(StatusCode.Forbidden, 'You may not classify support requests for this account')
    }
  },
})
```

This is separate from technical authentication. The test should prove that an
Account C request is denied before a scripted model is called, and that the
agent manifest lists only the read-only tool.
