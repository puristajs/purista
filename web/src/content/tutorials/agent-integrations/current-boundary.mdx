Harness supports MCP tools and Agent Plugins in its own integration surface.
The current PURISTA `AgentQueueBuilder` service runtime does not expose a
service-owned MCP or Plugin registry and no banking example binds one. This
chapter therefore does not claim an MCP round trip or a plugin review.

Do not work around the gap by starting a separate Harness application,
installing an unreviewed plugin at runtime, or adding an unrestricted HTTP
client. When PURISTA adds a typed attached-service binding, this page needs a
local fixture, allowlist, fault test, and proof that P1 still protects the
underlying bank command.
