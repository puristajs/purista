Keep model behavior deterministic in this tutorial. The example uses scripted
models, then asserts the service boundary rather than wording from a live model.

```ts title="The important assertions"
expect(definition.commandTools).toContain('banking.1.listTransactions')
expect(denied.status).toBe(403) // before any model request
expect(loadedSkillName).toBe('banking-support-playbook')
```

Test the generated agent builder first, then the complete Hono request. Add a
missing-Skill binding test so a configuration error fails at startup rather than
after a customer request.

```bash title="Run the focused agent tests"
npx vitest run examples/banking/src/ai/customer-support-classification.test.ts
npx vitest run examples/banking/src/ai/support-playbook.test.ts
```

Finally run the full application suite. These tests prove capability and access
control; they do not claim a live model's answer quality.

```bash title="Verify the runnable checkpoint"
npm run test -w @purista/banking-tutorials
```
