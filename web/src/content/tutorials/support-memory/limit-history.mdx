---
title: Keep chat history out of this checkpoint
description: Distinguish one explicit preference from retained message history and avoid claiming a chat-memory feature that is not built.
order: 142
status: published
---

Conversation memory and chat history are different data. This checkpoint does
not retain chat messages, summaries, prompts, account facts, or model output.
It retains only a language preference that the person selected.

That narrow design gives a beginner an important rule: decide exactly what
data is retained, for how long, and why before adding memory. If a later chat
feature keeps history, it must set an explicit context limit, show what is
retained, and extend the deletion proof. Do not describe this preference
example as a general conversation-history implementation.
