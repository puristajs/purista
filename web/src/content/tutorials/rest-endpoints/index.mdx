This chapter introduces the `Transaction` service because the application now
needs transaction behavior. It owns two commands: record one synthetic
transaction and read one by ID. Hono turns their builder metadata into REST
endpoints and OpenAPI paths.

The commands depend on a `TransactionRepository` resource. A small in-memory
adapter lets the chapter run, but the service never stores transaction records
in StateStore. The next chapter will replace that adapter with a database.
