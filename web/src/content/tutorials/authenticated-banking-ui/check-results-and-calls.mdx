---
title: Check returned data
description: Use an after guard to stop a read-only result that accidentally contains another account's rows.
order: 35
---

The statement handler queries one account. Add an after guard as a release
check: it verifies the result account ID and every row before Hono returns it.

```ts title="getStatementCommandBuilder.ts"
.setAfterGuardHooks({
  statementScope: async function (_context, result, _payload, parameter) {
    if (result.accountId !== parameter.accountId || result.transactions.some(row => row.accountId !== parameter.accountId)) {
      throw new HandledError(StatusCode.Forbidden, 'The statement contains data outside the authorized account')
    }
  },
})
```

An after guard protects a read-only response. It does not replace a scoped
repository query and it cannot undo a write that a handler already completed.
Keep business access checks before the handler and keep the repository query
scoped as well.
