---
title: Generate the protected read command
description: Generate an account statement command before adding the authentication and authorization rules that protect it.
order: 31
---

Create the read operation that needs its own account-level permission:

```bash title="Generate getStatement"
npm run add:command -- get-statement \
  --service banking --service-version 1 \
  --description "Return an account statement for an authorized reader"
```

The command generator adds a builder, schema, types, and test to the banking
service. Give its parameter schema an `accountId`, and make its output contain
that same account ID plus the transaction rows. Do not add `principalId` or
`tenantId` to the JSON request: those describe the caller and must be supplied
by the server.

The next pages add two facts separately: Hono establishes who the caller is;
the command guard decides whether that caller may read this account.
