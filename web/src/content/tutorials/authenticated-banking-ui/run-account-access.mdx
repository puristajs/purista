Start with the transaction API: Banking version 1 has `getBankInfo`,
`recordTransaction`, and `listTransactions`. Its repository stores synthetic
records in memory. It does not yet know which tenant or person owns a request.

If you completed the previous chapter, keep that application. Do not regenerate
its service or commands. If you arrived independently, use a terminal directory
that does not already contain these folders:

```bash title="Recreate the chapter's starting application"
git clone https://github.com/puristajs/purista.git
cd purista
node examples/banking/tutorial/replay.mjs --to list-transactions --out ../example-bank-access
cd ../example-bank-access
```

Use Node 24.15 or newer and npm. The replay installs published packages, runs
the PURISTA CLI, applies the preceding lessons' edits, and checks them. You do
not need to install the framework monorepo itself. If you already cloned it,
run the replay from that checkout with a new output directory.

## Check what you already have

Run the application's checks:

```bash title="Verify the starting transaction API"
npm test
npm run build
```

Expect six passing tests. Start `npm run dev`, then request
`http://127.0.0.1:3000/api/v1/bank` in another terminal with curl. It returns
the bank name and currency. Stop the server with Ctrl+C before continuing.

All commands below run inside your generated application, not the PURISTA
repository. The next pages create ordinary TypeScript modules with the exact
paths above their code blocks. The existing CLI-generated commands stay in
place; you will edit their builders. Near the end, you will use the CLI to add
a new `getAccountOverview` command.
