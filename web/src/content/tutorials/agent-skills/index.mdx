This chapter teaches how to add an [Agent Skill](https://agentskills.io/) to a
native Harness agent and mount that agent on a PURISTA service. A Skill is a
directory containing instructions and optional reference files. Harness shows
the model a small catalog first; the model reads the full `SKILL.md` only when
the current question needs it.

The Example Bank fixture contains one short support procedure. The capability
is useful for product manuals, operating procedures, style guides, and other
reviewed knowledge that belongs in source control.

```text title="Skill-enabled execution path"
PURISTA command
  -> EventBridge agent address
  -> business guard
  -> native Harness agent
  -> compact Skill catalog
  -> model selects the read tool when the Skill applies
  -> validated structured answer
```

A Skill supplies context. It cannot authenticate a caller, authorize an
action, reveal a secret, add a tool, or execute a script. PURISTA guards and
Harness tool and sandbox policies keep those decisions outside the prompt.

You will:

1. create a new PURISTA project, service, agent, and versioned Skill;
2. bind the Skill and its narrow `read` capability to the agent;
3. protect both the command and directly addressable agent with a business
   policy;
4. invoke the agent through EventBridge; and
5. test lazy loading, authorization, and fail-closed startup without an API
   key.

The complete runnable project is in
`examples/banking/chapters/agent-skills`.

Start with [Create the project and Skill](./build/create-skill/).
