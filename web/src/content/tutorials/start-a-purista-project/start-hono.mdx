## Create the HTTP startup function

Create `src/http.ts`:

```ts title="src/http.ts"
import { serve } from '@hono/node-server'
import type { EventBridge, Logger, Service } from '@purista/core'
import { honoV1Service } from '@purista/hono-http-server'
import { httpConfig } from './config/http.js'

/** Register the application's services before accepting HTTP requests. */
export async function startHttpServer(input: { eventBridge: EventBridge; logger: Logger; services: Service[] }) {
	const honoService = await honoV1Service.getInstance(input.eventBridge, {
		logger: input.logger,
		serviceConfig: httpConfig.serviceConfig,
	})
	honoService.registerService(...input.services)
	await honoService.start()

	const server = serve({
		fetch: honoService.app.fetch,
		hostname: httpConfig.hostname,
		port: httpConfig.port,
	})

	const closeSocket = {
		name: 'Example Bank HTTP socket',
		destroy: () =>
			new Promise<void>((resolve, reject) => {
				server.close(error => (error ? reject(error) : resolve()))
			}),
	}

	return { honoService, closeSocket }
}
```

`getInstance` creates PURISTA's Hono service with the existing EventBridge and
our configuration. `registerService` reads HTTP metadata from the supplied
services. We call it **before** `start()`; registration after startup is
rejected. The generated Ping command has no HTTP exposure, so it does not
create an endpoint yet.

`await honoService.start()` makes the service ready. `serve(...)` then opens
the Node socket. Its `fetch` field is Hono's request handler; its address and
port come from our configuration.

The function returns the Hono instance and an object that can close the socket.
A `Promise` lets shutdown wait until Node has finished closing that socket.

## Connect it to the entry point

Replace all of `src/index.ts`:

```ts title="src/index.ts"
import { gracefulShutdown, initLogger } from '@purista/core'
import { getEventBridge } from './eventbridge.js'
import { startHttpServer } from './http.js'
import { pingV1Service } from './service/ping/v1/pingV1Service.js'

async function main() {
	const logger = initLogger()
	const eventBridge = await getEventBridge(logger)
	const ping = await pingV1Service.getInstance(eventBridge, { logger })
	await ping.start()

	const { honoService, closeSocket } = await startHttpServer({
		eventBridge,
		logger,
		services: [ping],
	})

	gracefulShutdown(logger, [honoService.prepareDestroy(), eventBridge, ping, closeSocket, honoService])
	logger.info('Example Bank is listening on http://127.0.0.1:3000')
}

main().catch(error => {
	process.stderr.write(`${error}\n`)
	process.exit(1)
})
```

Startup now has an explicit order: bridge, Ping service, Hono routes, then the
network listener. The same bridge connects both services. The array
`services: [ping]` tells the HTTP setup which definitions to inspect.

`gracefulShutdown` registers signal handlers for stopping the process.
`prepareDestroy()` starts Hono draining; the remaining entries release the
bridge, service, socket, and Hono resources. The final `.catch(...)` reports a
failed startup and exits with a failure status.

## Make the first request

```bash title="Start the development server in terminal one"
npm run dev
```

This command stays running. It watches source files and restarts after an edit.
Warnings about the default stores describe development-only implementations;
this chapter does not configure production stores.

Open a **second terminal** and send a request:

```bash title="Check the running listener from terminal two"
curl -i http://127.0.0.1:3000/health
```

Expect HTTP status `200` and this body:

```json title="Health response"
{"status":200,"message":"OK"}
```

This proves Node and Hono are connected. It does not prove a banking command
works. A request to `/api/v1/bank` still returns `404`, because we have not
created that route.

If the terminal reports `EADDRINUSE`, another process owns port 3000. Stop
your earlier tutorial process, or change `port` in `src/config/http.ts` and
use that port in the request. If curl cannot connect, check terminal one for
a startup error.

Press **Ctrl+C** in terminal one before the next page. Next, [generate and
start the Banking service](/tutorials/start-a-purista-project/generate-banking-service/).
