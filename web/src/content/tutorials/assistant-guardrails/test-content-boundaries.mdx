Run the focused test:

```bash
npx vitest run examples/banking/src/ai/guarded-assistant.test.ts
```

The test starts the generated Hono endpoint and a real service-attached
Harness agent. It asserts the following runtime outcomes:

| Scenario | Expected result |
| --- | --- |
| Input contains the synthetic secret marker | Failure and zero provider requests |
| The read Skill returns an unsafe instruction | Failure after one request and before a second request |
| The candidate answer contains the marker | Failure after one request and no delivered answer |
| Bob asks about Account C | `403` and zero provider requests |

These tests prove execution order and fail-closed behavior for the committed
fixture. They do not prove live-model quality or a production safety policy.
Keep the existing P1 and P6 scope tests when you connect this pattern to a
real retrieval or tool implementation.
