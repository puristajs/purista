---
title: Check the final answer before delivery
description: Use a before-output interceptor so a blocked candidate answer is never returned to the caller.
order: 134
status: published
---

The final interceptor runs after the model creates an object and before the
agent output is validated, persisted, or delivered. It blocks the same
synthetic marker in the candidate answer.

```ts title="examples/banking/src/ai/guarded-assistant.ts"
{
  id: 'block-demo-secret-output',
  beforeOutput: ({ output }) =>
    containsDemoMarker(output, bankingDemoSecretMarker)
      ? { decision: 'block' }
      : undefined,
}
```

This example uses an aggregate HTTP response. That is important: no answer
token has reached the browser when the final check runs. A final check cannot
take back text already streamed to a client. For streaming applications, check
each release boundary before writing user-visible answer tokens.
