Run the banking example tests from the PURISTA repository root:

```bash title="Verify the grounded-answer checkpoint"
npm run test -w @purista/banking-tutorials
```

The test `streams an AI SDK UI response only from the caller-authorized
retrieved guide` does the following:

1. Signs in as Alice and submits a document to
   `POST /api/v1/knowledge/documents`.
2. Waits for the attached local worker to make the document searchable.
3. Signs in as Bob, who has an independent read mandate for Account A.
4. Sends a UI-message request to `POST /api/chat/knowledge` and verifies the
   event stream contains the guide text.
5. Requests `account-c-documents` as Bob and expects `403`.

That last assertion is essential. A green chat response alone would not prove
that account scope protects the source context. The test does not make a
network call or use a live model, so it is repeatable on a new local run.
