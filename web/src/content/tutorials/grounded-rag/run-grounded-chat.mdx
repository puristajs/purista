Use this page when you want to see the finished result before reading the
implementation details. You need Node.js 24.15 or later and the Example Bank
dependencies already installed.

From the `purista` repository root, prepare the static UI and start the local
server:

```bash title="Start the Example Bank"
npm run build:ui -w @purista/banking-tutorials
npm run dev -w @purista/banking-tutorials
```

Open `http://127.0.0.1:3010/`. Choose **Alice**, sign in, and keep **Account
A** selected. In the **Ask the account guide** panel:

1. Select **Ingest sample guide**.
2. Wait until the green message says the ingestion command accepted the guide.
3. Enter `What does a monthly statement explain?`.
4. Select **Ask account guide**.

The answer contains the guide’s statement-and-balance wording. There can be a
short wait after ingestion because the local worker processes the queued
document. If the answer says it cannot find a passage, wait briefly and submit
the question again.

The UI uses a local opaque session cookie. It sends that cookie with its
ingestion request and chat request. The server reads the corresponding
server-side session record; the UI does not send a principal or tenant ID in
either request.

The UI has no upload feature. **Ingest sample guide** always submits a small,
synthetic account guide. The chat only shows text message parts. It does not
render the answer command’s `sources` list as citation links or source cards.
