This chapter teaches sandboxed tool execution as a Framework capability. You
create a PURISTA service and command, define a native Harness agent, and bind a
sandbox adapter only at runtime. The agent writes an input file, runs a small
Python program, reads the result, and returns a structured recommendation.

The Example Bank data keeps the task concrete without adding business
complexity. The analysis is advisory; a separate guarded command would own any
effect such as blocking a transaction.

The optional live path runs in a non-root container with networking disabled
and an application-selected image. The fast default path uses a local directory
to teach and test the same tool loop without claiming process isolation.
