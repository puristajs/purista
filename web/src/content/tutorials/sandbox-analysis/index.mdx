This chapter builds one protected PURISTA analysis command. The agent can write a CSV file, run one allowed Python command, read the result, and return typed data.

The default path uses a temporary local directory. It proves Harness tool permissions and the agent loop without an API key or Docker. It is process-local and is **not** a process-isolation boundary. The later Docker path is optional and adds a non-root container boundary.
