Create a fresh project. The generated service owns every final agent and Harness file.

```bash title="Create and enter the project" replay="parent"
npm create purista@3.0.0 sandbox-analysis -- --runtime node --event-bridge default --non-interactive --defaults
cd sandbox-analysis
```

Install once, then generate each boundary once. The agent stays internal; the command is the public service target.

```bash title="Install dependencies" replay="project"
npm install
```

```bash title="Generate Analysis boundaries" replay="project"
npm run add:service -- analysis --description "Own isolated transaction analysis" --non-interactive
npm run add:agent -- analyze-transactions --service analysis --service-version 1 --http none --description "Analyze transactions in a sandbox" --non-interactive
npm run add:command -- run-analyze-transactions --service analysis --service-version 1 --description "Run protected transaction analysis" --non-interactive
```
