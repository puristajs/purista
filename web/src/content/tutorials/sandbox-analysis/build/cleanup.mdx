title: Manage sandbox retention
description: Separate request attachment shutdown from deliberate administrative cleanup of retained sandbox resources.

---

Normal request completion releases the live sandbox attachment. It should not
silently turn a model call into a destructive retention purge. Retained
resources may be useful for audit or debugging, subject to the application's
data policy.

Use the sandbox adapter's trusted administration interface from an
operator-owned command or scheduled job. Select resources by owner or age, keep
that operation unavailable to agents, and handle its result explicitly:

- `completed` means the selected cleanup finished;
- `partial` carries a continuation cursor that the job must persist and retry;
- `failed` requires an operational retry or investigation.

Stop the local Compose resources when the lesson is complete.

```bash title="Remove local sandbox containers" replay="project"
docker compose down --remove-orphans
```
