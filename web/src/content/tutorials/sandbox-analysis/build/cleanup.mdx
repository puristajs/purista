title: Release and purge sandbox resources
description: Separate request attachment shutdown from destructive retention cleanup and make administrative retries explicit.
order: 284
kind: lesson
status: draft
---

Normal request completion releases the live sandbox attachment. It does not
silently turn a model call into an administrative purge. Retention cleanup uses
the sandbox adapter's trusted administration interface with an explicit owner
or age selector.

An administrative result can be `completed`, `partial`, or `failed`. Persist
the continuation cursor for a partial result and retry from that cursor. Keep
this operation behind an operator-owned command or scheduled job; never expose
it as an agent tool.

Stop the local Compose build resources when the lesson is complete.

```bash title="Remove local sandbox containers" replay="project"
docker compose down --remove-orphans
```
