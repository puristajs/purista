
Generate the Analysis service, native agent, and application command.

```bash title="Generate the analysis boundaries" replay="project"
npm run add:service -- analysis --description "Own isolated analysis jobs" --non-interactive
npm run add:agent -- analyze-transactions --service analysis --service-version 1 --description "Analyze one transaction dataset in a sandbox" --non-interactive
npm run add:command -- analyze-transactions --service analysis --service-version 1 --description "Run an isolated transaction analysis" --non-interactive
```

This example keeps its compact agent and tool definitions in one Harness file.
Remove the generated agent placeholder before writing it.

```bash title="Remove superseded generated agent files" replay="project"
rm -rf src/harness/analysis/agent
```

Build a small non-root image. The model never chooses an image tag or runtime
socket; the trusted composition root binds an immutable image id.

```dockerfile title="sandbox.Dockerfile" write
FROM python:3.13-slim
RUN useradd --create-home --uid 10001 sandbox
WORKDIR /workspace
USER sandbox
```
```yaml title="compose.yaml" write
services:
  sandbox-image:
    image: purista-tutorial-sandbox:local
    build:
      context: .
      dockerfile: sandbox.Dockerfile
    command: ["python3", "--version"]
```
```bash title="Build the local sandbox image" replay="project"
docker compose build sandbox-image
```
