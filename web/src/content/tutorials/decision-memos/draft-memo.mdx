`decisionMemoSchema` requires every claim to name at least one source ID. It
also requires a terminal status: `ready-for-human-review` or `unresolved`.
There is deliberately no `published` status on this artifact.

```ts title="examples/banking/src/memos/contracts.ts"
claims: z.array(z.object({
  text: z.string().min(1),
  sourceIds: z.array(z.string().min(1)).min(1),
})).min(1),
status: z.enum(['ready-for-human-review', 'unresolved']),
```

Typed output catches broken fixtures and later model output at the service
boundary. It does not prove a cited source supports a claim; the next step does
that deterministic check.
