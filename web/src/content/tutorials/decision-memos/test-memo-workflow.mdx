The focused test covers the complete path and the unsafe path:

```bash
npm test -- --run src/service/bankingDecisionMemos/v1/command/requestDecisionMemo
npm test -- --run src/service/bankingDecisionMemos/v1/queue-worker/createDecisionMemoWorker
npx vitest run examples/banking/src/memos/service.test.ts
npm run typecheck -w @purista/banking-tutorials
```

It verifies a stable queue request, duplicate-worker safety, a review-ready
memo with approved citations, an unresolved memo after its budget, and an
authorization denial for a customer. Add the memo to a publishing flow only
after a separate reviewer command has been designed and tested.
