A command transform converts a supported representation at the service
boundary. It does not contain business effects and it does not authorize a
caller.

This chapter adds two focused Transaction commands:

- an input transform converts `debit|25.99|Northwind Books|Order 1042` into the
  existing domain fields with `2599` cents;
- an output transform converts one authorized transaction into explicit CSV.

The existing account guards still decide whether the principal may import or
export that account's data.

2. [Transform output after authorization](/tutorials/command-transforms/build/output/).
