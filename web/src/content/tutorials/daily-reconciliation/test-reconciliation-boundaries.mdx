Test the business boundary before testing time. The reference calls the command
as Dana, the only fixture user assigned to `banking-projections` in
`tenant-north`, and then verifies that an unassigned caller receives `403`.

```ts title="advanced/service.test.ts"
expect(queued.queueName).toBe('banking.runReconciliation')
await expect(runReconciliation.getCommandFunction().call({}, unassignedContext, payload, {}))
  .rejects.toMatchObject({ statusCode: 403 })
```

Also test an invalid date, an unknown source (once your schema permits more
sources), a repeated occurrence, and the worker's stored count. These tests are
independent of a real clock and should stay fast.

```bash title="Verify the full runnable example"
npm run typecheck
npm test
```

For a production scheduler, add a separate integration suite with the selected
adapter. Keep it opt-in when it requires Docker or cloud credentials.
