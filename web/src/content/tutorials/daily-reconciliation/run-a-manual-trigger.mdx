---
title: Generate the manual trigger
description: Create an operations command with the PURISTA CLI before connecting it to the queue.
order: 81
---

Create the request boundary first. A manual run is an operations action, so it
belongs to its own command rather than the customer banking service.

```bash title="Generate the reconciliation command"
npm run add:command -- run-reconciliation \
  --service banking-operations --service-version 1 \
  --description "Queue a manual reconciliation run for one banking day"
```

The CLI creates a command folder and its test below
`src/service/bankingOperations/v1/command/runReconciliation/`. Replace the
starter schemas with the typed `day` and `source` contract in the next step.
Do not add HTTP code by hand; expose the completed command as
`POST reconciliation/run` in its builder.

```bash title="Check the generated command before editing it"
npm test -- --run src/service/bankingOperations/v1/command/runReconciliation
npm run typecheck
```
