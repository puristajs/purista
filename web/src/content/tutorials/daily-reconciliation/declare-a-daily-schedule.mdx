---
title: Declare the daily schedule
description: Generate a schedule declaration that emits the same typed event used by the manual command.
order: 85
---

The CLI currently generates services, commands, subscriptions, streams, queues,
workers, and agents; it does not yet generate schedules. Add the declaration to
the existing CLI-created `banking-operations` service rather than creating a
second timer outside PURISTA. Reuse the event contract from this chapter:

```ts title="dailyReconciliation schedule"
.emitEvent(BankingTutorialEvent.reconciliationDue, {
  expression: { kind: 'cron', value: '5 2 * * *', timezone: 'Europe/Berlin' },
  missedRunPolicy: 'runOnce',
  payloadSchema: reconciliationDueEventSchema,
})
```

The declaration says *what* should happen and how a missed occurrence is
treated. It does not start a scheduler host by itself. Select a production
scheduler and queue bridge before depending on time-based financial operations.

```bash title="Verify the service still composes"
npm run typecheck
```
