The test starts the actual attached service through the Hono adapter. It checks
the generated workflow definition, a complete Case A brief, the explicit
partial path, and the P5 denial for Case C.

```bash
npx vitest run examples/banking/src/investigation/service.test.ts
npm run typecheck -w @purista/banking-tutorials
```

The denial assertion is especially important: it confirms that Case C does
not start the workflow and releases no case evidence. A quality score or a
later model check can never replace this business authorization test.
