title: Return an honest partial brief
description: Preserve source-backed findings and show a missing branch instead of inventing a conclusion.

---

The case brief has exactly three named findings. A successful finding has a
conclusion and source IDs. A failed specialist becomes an `unavailable`
finding with `specialist-failed` and no evidence. The overall brief is then
`partial`.

```ts title="examples/banking/src/investigation/service.ts"
return unavailableFindingSchema.parse({
  branch: branch.branch,
  status: 'unavailable',
  reason: 'specialist-failed',
  evidence: [],
})
```

The `case-account-a-missing-support` fixture exercises this path. It teaches a
useful rule for real investigations: an unavailable source is a result to show
to a person, never a gap for the system to fill with a plausible answer.
