Open the generated subscription builder. The CLI created the files; now add the
business connection and consumer-local input schema.

```ts title="monitorRecordedTransactionSubscriptionBuilder.ts"
.subscribeToEvent('banking.transaction.recorded')
.addPayloadSchema(transactionRecordedEventSchema)
.setSubscriptionFunction(async function (context, payload) {
  // The next step writes one idempotent review case.
})
```

Register `monitoringV1Service` beside the banking service in `src/index.ts`.
The consumer receives the event through the EventBridge. It does not become a
function called by `recordTransaction`.
