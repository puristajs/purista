---
title: Publish the transaction fact
description: Declare a small event payload and emit it only after a successful transaction write.
order: 52
---

An event is a fact that happened. It is not a request to the monitoring service.
Add a narrow `transactionRecorded` event schema: transaction ID, account ID,
amount in minor units, currency, direction, and booking time. Do not copy every
HTTP field into the event.

In `recordTransactionCommandBuilder.ts`, declare that the command may emit the
event and publish it after the repository accepts the transaction:

```ts title="recordTransactionCommandBuilder.ts"
.canEmit('banking.transaction.recorded', transactionRecordedEventSchema)
.setCommandFunction(async function (context, payload) {
  const transaction = context.resources.bankingRepository.record(payload)
  await context.emit('banking.transaction.recorded', toRecordedEvent(transaction))
  return transaction
})
```

The command emits no event when its posting guard denies the request or the
repository rejects conflicting data. The default local EventBridge is in memory:
it proves the interaction in one process, not durable publication or replay.
