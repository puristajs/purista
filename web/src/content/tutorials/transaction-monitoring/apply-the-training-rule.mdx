---
title: Apply the training rule
description: Store one review signal for a high-value synthetic transaction without taking action against an account.
order: 54
---

Inject a `reviewCaseRepository` into the monitoring service. In the
subscription handler, return for amounts below `100000`. For other amounts,
save a case with the transaction ID, account ID, `review-required`, and the
fixed reason `amount-at-or-above-training-threshold`.

This deterministic rule is a training signal. It does not classify a customer,
freeze an account, or claim regulatory detection. Expose a guarded
`listReviewCases` command only for the assigned synthetic reviewer.
