---
title: Generate the monitoring boundary
description: Generate a separate monitoring service and its subscription before writing the event contract or rule.
order: 51
---

Create a versioned service for the independent responsibility, then generate
its event handler:

```bash title="Generate monitoring service and subscription"
npm run add:service -- monitoring --description "Create synthetic transaction review signals"
npm run add:subscription -- monitor-recorded-transaction \
  --service monitoring --service-version 1 \
  --event banking.transaction.recorded \
  --description "Create one review signal for a recorded transaction"
```

The CLI adds `src/service/monitoring/v1/` and the subscription folder beneath
it. The generated subscription has schemas, a builder, and a test. Its handler
is intentionally empty until the event contract and idempotency rule exist.

```bash title="Check the generated consumer"
npm run build
npm test
```
