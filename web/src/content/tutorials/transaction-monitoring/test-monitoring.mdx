Write one runtime test that starts both services with `DefaultEventBridge`.
Record a normal transaction and assert no case exists. Record a transaction at
the threshold and assert one case exists. Deliver the matching event again and
assert there is still one case.

Also keep the business denial test: a blocked transaction post returns `403`,
does not write a transaction, and emits no event. Run the whole checkpoint:

```bash title="Run the event and subscription tests"
npm test
```

The local test proves in-process delivery and consumer behavior. Durable
publication, replay, and recovery belong to the distributed operations chapter.
