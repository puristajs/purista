Run the example checks from the `purista` repository root:

```bash title="Typecheck and test transaction monitoring"
npm run typecheck -w @purista/banking-tutorials
npm run test -w @purista/banking-tutorials
```

`examples/banking/src/advanced/service.test.ts` creates a real subscription
context with `createSubscriptionContextMock`, calls the registered subscription
function, and asserts that a `100000`-minor-unit event creates a finding. The
same file starts the full advanced service definition with both local bridges.

This proves the schema-shaped handler and its in-memory projection. It does
not prove HTTP access to findings, investigator assignment, durable delivery,
replay, transactional publication, or a process-restart recovery path. Those
features need source, infrastructure, and integration tests before a tutorial
can claim them.

When you extend this checkpoint, test all three outcomes: an allowed posting
emits the expected fact, a denied posting writes no transaction and emits no
event, and a repeated matching event creates one logical finding.
