---
title: Prepare the browser project
description: Add the browser build dependencies to the CLI-created PURISTA project before writing its first screen.
order: 11
---

Start in the `example-bank` directory created by the PURISTA CLI. The generator
gave you a backend and a `public` directory. Add React and Vite as the browser
build tools; PURISTA still owns the HTTP server and business services.

```bash title="Install the browser build dependencies"
npm install react react-dom
npm install --save-dev vite @vitejs/plugin-react @types/react @types/react-dom
mkdir -p ui/src
```

Vite watches and builds the browser files. It does not become a second
production server. Create these files in the new directory:

```text title="Browser files added in this chapter"
ui/
├── index.html
├── vite.config.ts
└── src/
    ├── App.tsx
    ├── main.tsx
    └── styles.css
```

The full runnable reference has the same layout in
`examples/banking/ui`. Use it after a step to compare your result, not as code
to copy before you understand the changes.
