---
title: Make your first visible change
description: Change the first React screen, rebuild its assets, and verify the exact browser result.
order: 14
---

Make a small change in one place so you can see the complete edit-to-browser
loop. In your `ui/src/App.tsx`, change the heading to `Example Bank — local`.

```bash title="Build the React UI"
npm run build:ui
```

Reload `http://127.0.0.1:3000/`. You should see the new heading. Return it to
`Example Bank` before continuing, so later tests and screens have one stable
expectation.

The page is a built browser asset. A React source change needs a Vite build;
the Hono server serves the newly built files. If the browser still shows the
old text after a successful build, perform a hard refresh.

```bash title="Verify the restored page"
curl --fail http://127.0.0.1:3000/ | grep 'Example Bank'
```
