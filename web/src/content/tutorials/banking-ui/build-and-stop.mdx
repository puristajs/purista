description: Verify the browser assets and generated PURISTA project before adding transaction behavior.

Check that the browser assets and generated project both build:

```bash title="Build and test the current checkpoint"
npm run build:ui
npm run build
npm test
```

`build:ui` produces browser assets. `build` type-checks the generated PURISTA
application. `start` runs the TypeScript entry point once:

```bash title="Run the non-watch entry point"
npm run start
```

Open the root page, then press `Ctrl+C`. The generated `gracefulShutdown`
registration in `src/index.ts` closes the Node listener, Hono service, generated
services, and local EventBridge. Confirm that the port is free by requesting it
again; `curl` should fail to connect.

This checkpoint has no transaction data yet. The next chapter turns the
CLI-generated `banking` service and `recordTransaction` command into a REST API.
