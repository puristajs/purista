A browser interface gives you another way to try the bank's operations. It is
an optional extension after the backend works; no earlier chapter requires React.

Start with [the first HTTP service](/tutorials/start-a-purista-project/) and
its verified `first-command` checkpoint. You already have `src/config/http.ts`,
`src/http.ts`, and a Banking service registered with Hono. Do not generate a
second application or replace that startup with the combined demo.

The pages below add browser build tools and static files to that application.
The bank's business behavior remains in its PURISTA services. Serving a page
does not grant access to any account.

1. [Prepare the browser project](/tutorials/banking-ui/run-the-project/).
2. [Locate the existing Hono server](/tutorials/banking-ui/start-hono/).
3. [Serve the browser page](/tutorials/banking-ui/serve-react/).
4. [Make a visible change](/tutorials/banking-ui/change-the-page/).
5. [Build and stop the application](/tutorials/banking-ui/build-and-stop/).
