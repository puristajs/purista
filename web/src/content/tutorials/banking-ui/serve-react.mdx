---
title: Serve the browser page
description: Build a small React screen and add Hono static routes that serve it from the PURISTA application.
order: 13
---

Create `ui/src/App.tsx` with a visible, honest first screen:

```tsx title="ui/src/App.tsx"
export const App = () => (
  <main>
    <p>Example Bank tutorial</p>
    <h1>Example Bank</h1>
    <p>Synthetic display data. Transaction features arrive in the next chapter.</p>
  </main>
)
```

Create `ui/src/main.tsx` to mount `App`, then create a Vite config whose root
is `ui` and whose build output is `ui/dist`. The checked-in reference
equivalents are in `examples/banking/ui`.

Add static routes to generated `src/http.ts` before `await honoService.start()`:

```ts title="src/http.ts"
honoService.app.get('/assets/*', serveStatic({ root: './ui/dist' }))
honoService.app.get('/', serveStatic({ root: './ui/dist', path: 'index.html' }))
```

Add the build script to `package.json`:

```json title="package.json"
{ "scripts": { "build:ui": "vite build --config ui/vite.config.ts" } }
```

```bash title="Build the browser files and start PURISTA"
npm run build:ui
npm run dev
curl --fail http://127.0.0.1:3000/
```

The response must contain `Example Bank`. If it is not present, rebuild the UI
and check that `src/http.ts` points to `ui/dist`.
