This extension uses the server you built in
[Connect and start Hono](/tutorials/start-a-purista-project/start-hono/).
If you have not built it yet, that lesson shows the package installation,
configuration, complete startup files, and health request.

Open `src/http.ts`. Its `startHttpServer` function creates the Hono service,
registers the supplied PURISTA services, starts Hono, and opens the local Node
socket. `src/index.ts` supplies the Banking instance and arranges shutdown.

The settings are in `src/config/http.ts`: localhost port 3000, the
`/health` route, and the `/api` prefix. Confirm the backend still works
before changing how it serves files:

```bash title="Start the existing backend"
npm run dev
```

In another terminal:

```bash title="Check the backend before adding a UI"
curl -i http://127.0.0.1:3000/health
curl -i http://127.0.0.1:3000/api/v1/bank
```

Expect `200` for both. The second response is
`{"name":"Example Bank","currency":"EUR"}`. Leave business commands in their
service files; static serving belongs in the HTTP setup.

Stop the server with Ctrl+C before continuing to
[serve the browser page](/tutorials/banking-ui/serve-react/).
