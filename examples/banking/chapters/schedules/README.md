# Example Bank: create a PURISTA project

This project was built by following the PURISTA project tutorial. Use Node.js
24.15 or newer. Run `npm ci`, `npm test`, and `npm run build` in this directory.

The project contains a CLI-generated BankProfile v1 service and `getProfile`
command. It has no HTTP server, UI, database, authentication, broker, or AI.

Tutorial: https://purista.dev/tutorials/create-project/
